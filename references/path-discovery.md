# 路径自主发现（继承 V1.2 A–H，V2 重组：阶段 / 加速器 / 核验门禁三分离）

触发条件：任务引用本机文件、项目、配置、Skill 或报告，但未提供精确路径。此时**禁止在未搜索的情况下向用户索要路径**。

## 1. 搜索阶段（按优先级逐级，命中即停）
- A. 当前工作目录 / 当前项目（最小范围优先）
- B. Agent 已知项目与近期工作记录（工作区、会话历史、任务台账）
- C. Git 仓库 / 配置 / 历史记录（远程、分支、提交日志、shell history）
- D. 用户主目录 / 桌面 / 文档 / 常用开发目录（一级子目录扫描）
- E. 全部可访问本地磁盘（有界递归，按目标关键词/文件名剪枝）

宿主历史记录位置（作为 B/C/D 级**搜索提示**，动态检测，不假设所有电脑相同）：
- 各 Agent 的 sessions/projects/tmbs/ledger 目录通常在其应用数据目录（如 `~/.<agent>`）下；先检测 `~/.<agent>` 是否存在，不存在则该来源标记 UNVERIFIED 并跳过。
- 宿主可通过环境变量或首次探测提供确切位置；Agent 不得硬编码某台电脑的绝对路径。

## 2. 搜索加速器（方法，不属于必经阶段，可与阶段叠加使用）
- F. 优先使用已有文件索引工具（ripgrep、Everything、IDE 索引）加速。
- G. 索引不可用时采用有界递归搜索。
  - **默认参数**：递归深度 4、单磁盘限时 90 秒、最多保留 3 个候选（超限按匹配度+时间截断）。
  - 禁止无界全盘扫描。
- 加速器失败或超时必须记录，转入核验或询问路径，不得无限递归。

## 3. 核验门禁（H：对候选结果做实际核验，不得仅凭目录名相似即认定归属）
必须结合**至少两类相互独立的证据**：
- Git remote / branch / HEAD
- 项目结构（目录树、入口文件、manifest）
- 配置引用（.env.example、Makefile、CI 脚本中引用该路径）
- 文件内容 / 必要元数据
- 当前运行实例（端口、PID、workspace 绑定）

**同名项目误选防护**：同名候选必须结合任务词、项目结构、Git 信息三项中至少两项排除误选（例如 collector 与 publish 两个同名项目，按任务词“采集”+结构（数据目录 vs 发布脚本）+Git 远端区分）。

**执行报告 vs Skill 文件 vs 模板的判定（防 11-05 场景 3 误判复发）**：
- 真实执行报告：含 FINAL_STATUS/收口标记 + 真实运行数据（时间戳、Run ID、测试结果）+ 交付物索引，且非模板。
- Skill 源文件 / 任务指令 / examples 模板：不含真实运行数据，一律排除，不得当作执行报告。

## 4. 禁止行为
- 未搜索就询问用户路径
- 搜索一个默认目录失败即放弃
- 找不到 Skill 就要求用户手动定位
- 没有证据就猜测项目目录
- 因同名文件擅自选择错误项目
- 重复搜索已确认命中的路径
- 以搜索为由读取无关敏感数据（密钥、Token、Cookie、个人隐私）

## 5. 允许询问用户的唯一条件（满足且仅满足以下之一）
1. 已完成合理搜索（A→E 全部覆盖，含加速器），仍无法找到目标
2. 存在 ≥2 个无法区分的有效候选
3. 目标目录不可访问（权限不足），需用户授权
4. 目标位于尚未挂载/未连接的存储设备

询问时必须附：已搜索范围、发现候选、缺少什么证据、为何无法自主解决。

## 6. 收口标记
- 路径发现结果写入报告的 GAPS/ACCEPTANCE：`PATH_FOUND=<路径>` 或 `PATH_ASKED=<询问理由>`。
