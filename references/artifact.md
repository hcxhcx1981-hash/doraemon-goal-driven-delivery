# ARTIFACT 任务规则（文档/PPT/表格/网页；references 一层引用自 SKILL.md）

适用：交付物为文档、PPT、表格、网页、演示。PPT 是 ARTIFACT 的子类型（专项流程见下），不新增顶层任务类型。

## 判型与子类型（单一真源见 machine-fields.md）
- 判型：交付物为文档/PPT/表格/网页 → TASK_TYPE=ARTIFACT；混合交付取主类，次类写 GAPS。
- PPT 子类型触发条件：交付物为演示幻灯片（.pptx/.key 或可导出幻灯片）。

## 执行流程（通用）
需求与受众 → 内容结构 → 视觉/排版方案 → 制作 → 导出 → 逐页/逐节检查 → 最终交付

## PPT 专项流程（ARTIFACT 子类型，在通用流程上细化）
1. 先定大纲与逐页要点（标题、关键信息、视觉支持），再制作；页序不得事后凭印象调整。
2. 每页固定画幅（如 1280x720），无滚动区、无裁剪文字、无溢出；文字必须完整可见。
3. 图按比例默认 contain，不拉伸、不裁掉关键内容；相关源图优先，但可用结构化图表/时间线/矩阵替代，不为凑图加无关图片。
4. 数据与断言逐页回指来源；示意素材必须标注，不编造。
5. 逐页/逐节渲染复检（文字裁剪、字体、比例、一致性）后才导出；导出失败只修该页，不整稿重写。
6. 收口：DELIVERED 写最终文件路径与格式；ACCEPTANCE 含"文件可打开+无裁剪+数据来源可回指"；任一断言无来源 → PARTIAL。

## 规则
1. 内容正确优先于视觉效果；不编造数据、案例、图片、成果。
2. 真实素材与示意素材必须区分标注。
3. 内容结构与版式设计分离；尊重已确认的设计母版。
4. 图片保持原始比例（contain 默认）；不拉伸、不裁剪掉关键内容。
5. 逐页/逐节检查：文字裁剪、字体、比例、清晰度、页面一致性。
6. 必须实际打开或渲染最终文件验收（不能仅凭"文件已生成"声称完成）。
7. 数据来源可回指：每个演示断言必须有来源或明确标注为示意/假设。
8. 导出失败只修该页/该节，不整稿重写；裁剪复检通过后交付。

## 收口补充
DELIVERED 写清最终文件路径与格式；ACCEPTANCE 含"文件可打开 + 无裁剪 + 数据来源可回指"三条件；任一演示断言无来源 → PARTIAL。
