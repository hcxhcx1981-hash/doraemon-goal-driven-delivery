# 安全边界与熔断

[规范原文](../SKILL.md) · [返回 README](../README.md)

本 Skill 不替代 Agent 的权限控制、安全机制、平台规则、项目 AGENTS.md、AUTHORIZED 门禁或生产审批。不授予新权限。开发守卫与本规则叠加，不覆盖、不合并替换。

- 同一根因最多 2 轮有证据修复；全任务默认最多 4 轮有效修复；更严格限制优先。
- 没有新证据立即熔断。不得拆分任务、改名或重启会话规避计数。
- 同根因两轮未解、破坏已通过功能、关键证据不足、时间/调用/额度预算耗尽、需要越权时停止相关修复。
- 每轮必须记录根因假设、支持证据、最小修改、验收方式。禁止无依据重试或无限重试。
- 禁止自动购买额度、无界调用外部模型、重复付费证明稳定或绕过节流；额度未知写 QUOTA=UNKNOWN。
- 禁止绕过生产安全门禁；不上传密钥、Token、Cookie、.env、隐私、用户记忆、本地配置、内部报告、日志或真实业务数据。
- 熔断后依次停止、保留已通过成果、保存必要错误证据、记录已试修复、标记 BLOCKED/PARTIAL、给出建议、交当前宿主总控/派工方裁决（V2 取消 ChatGPT 单控绑定）。

越权、生产/真实数据风险、不可逆删除覆盖迁移、高风险权限变更、凭据外传、新费用/超预算及实质业务冲突须暂停。普通技术选型不交给用户裁决。技术总控也不能撤销平台安全拒绝。

公开材料只含通用规则、说明与合成示例。维护者发布前逐文件审阅、检查 Git 跟踪清单、扫描凭据与隐私路径、确认许可证来源；发现第三方权属不明材料时排除并暂停发布该部分。测试中的合成场景不是生产数据。安全扫描不能保证不存在任何秘密，人工审阅仍必要。
