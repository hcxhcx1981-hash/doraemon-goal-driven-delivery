# 项目规则示例

本文件是模板，复制到自己的项目后按实际情况调整；不是本仓库额外授权。

- 开始前确认项目路径与 git status --short。
- 不读取、打印或提交 .env、凭据、隐私、用户记忆与本地配置。
- 先理解结构，做最小可回滚修改，不绕过项目安全门禁。
- 显式加载 doraemon-goal-driven-delivery V2.0.2；开发守卫单独叠加。
- 同根因最多 2 轮、全任务最多 4 轮有证据修复；无新证据立即熔断；不拆分规避预算。
- 运行项目已有验证命令，不编造通过；真实行为未验证写 UNVERIFIED。
- 仅在明确授权下提交、推送或发布；完成验收即停止。
