# 验收报告模板（非真实运行证据）

- GOAL：填写授权目标。
- DELIVERED：填写实际产物与入口。
- ACCEPTANCE：填写真实命令、退出码、回读/渲染结果；未运行写 UNVERIFIED。
- GAPS：NONE 或具体阻塞与下一步建议。
- REPOSITORY：分支、commit、远端同步状态；未授权推送写 NOT_PUSHED。
- FINAL_STATUS：PASS / PARTIAL / BLOCKED（依据证据选择）。
- QUOTA：UNKNOWN 或真实可读取的值。

修复账目每轮记录：根因标识、根因假设、支持证据、最小修改、验收方式、根因累计次数、全任务累计次数。没有新证据停止；计数不因拆分或重启清零。

熔断时追加：停止原因、已保留成果、脱敏错误证据、已试方案、当前宿主总控/派工方裁决建议（V2 取消 ChatGPT 单控绑定）。不要公开日志、秘密或内部报告。
